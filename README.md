# Cool Calculator

Cool Calculator is a browser-based calculator with a custom interface and interactive calculation features. This is an ongoing project, and some buttons still need improvement.

## Built With

- HTML for the structure
- CSS for styling and layout
- JavaScript for calculator functionality
- C# for the original console calculator

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Use the calculator buttons to perform calculations.

No additional installation is required to run the frontend.
