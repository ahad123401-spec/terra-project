# Cool Calculator

## About the Project

Cool Calculator is a browser-based calculator built as a programming project to explore frontend development and interactive user interfaces. It combines a custom-designed calculator interface with JavaScript functionality, allowing users to perform calculations directly in their web browser.

The project also includes an original C# console calculator, which was developed separately. Building both versions provided an opportunity to work with different programming languages and approaches to creating a functional application.

## Features

- Custom calculator interface with a dedicated layout.
- Interactive number and operation buttons.
- Browser-based functionality using JavaScript.
- Styling and layout created with CSS.
- A separate C# console calculator included in the repository.

Most of the browser calculator's buttons currently work, although some still need improvements. This version represents the initial functional stage of the project rather than the final release.

## Technologies Used

### HTML
HTML provides the structure of the calculator, including its display, buttons, navigation, and other interface elements.

### CSS
CSS is used to style the interface, organize the layout, and create a consistent visual appearance.

### JavaScript
JavaScript handles the interactive parts of the browser calculator and processes user input.

### C#
C# was used to develop the original console-based calculator, which remains part of the project.

## How to Try the Calculator

### Online Demo

You can try the browser version here:

https://ahad123401-spec.github.io/terra-project/

Open the link in a modern web browser and try entering numbers and using the calculator's operation buttons.

### Run Locally

To run the browser version on your computer:

1. Download or clone this repository.
2. Locate `index.html`, `style.css`, and `script.js`.
3. Keep these three files in the same folder.
4. Open `index.html` in a modern web browser.
5. Use the calculator directly in the browser.

The browser frontend does not require any additional installation.

The C# console version is separate. To run it, open the project in a suitable .NET environment and run the C# project.

## Current Development Status

The browser calculator has a working frontend and supports most of its intended interactions. Some buttons are not fully functional yet, and further testing and refinement are needed.

The project is still under development, so its current functionality should be considered an early version.

## Future Improvements

Planned improvements include:

- Fixing buttons that do not work correctly.
- Adding more calculator operations and features.
- Improving the interface and overall usability.
- Testing the calculator more thoroughly.
- Refining the project as development continues.

## Project Goal

The goal of Cool Calculator is to build a useful, interactive calculator while gaining practical experience in programming, frontend development, debugging, and improving an application through iterative development.
